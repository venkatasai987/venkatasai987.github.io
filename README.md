## Recommended deployment

For the clean URL `https://venkatasai987.github.io/`:

1. Create a **public** GitHub repository named exactly `venkatasai987.github.io`.
2. Extract this ZIP.
3. Upload/push the files **directly to the repository root**:
   - `index.html`
   - `style.css`
   - `script.js`
   - `resume.pdf`
   - `README.md`
4. Commit to the `main` branch.
5. Open repository **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select **main** and **/(root)**, then save.
8. Wait for GitHub Pages deployment to finish.
9. Visit `https://venkatasai987.github.io/`.
